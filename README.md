# Learning Resources

A lifelong, curated collection of learning resources — courses, books, articles, videos, and tools — that I need at any point in my life.

## How it's organized

Each topic has its own folder with a `README.md` containing a table of resources. New finds that haven't been sorted yet go into [INBOX.md](INBOX.md).

| Topic | What goes here |
|---|---|
| [Programming](programming/README.md) | Languages, frameworks, and general software engineering. |
| [Data Structures & Algorithms](data-structures-algorithms/README.md) | DSA, problem solving, and interview prep. |
| [System Design](system-design/README.md) | Architecture, distributed systems, and scalability. |
| [AI & Machine Learning](ai-ml/README.md) | ML, deep learning, LLMs, and data science. |
| [DevOps & Cloud](devops-cloud/README.md) | Infrastructure, CI/CD, containers, and cloud platforms. |
| [Career](career/README.md) | Resumes, interviews, communication, and leadership. |
| [Personal Finance](personal-finance/README.md) | Investing, taxes, budgeting, and money management. |
| [Health & Fitness](health-fitness/README.md) | Exercise, nutrition, sleep, and mental health. |
| [Languages](languages/README.md) | Learning spoken and written languages. |
| [Miscellaneous](miscellaneous/README.md) | Anything that doesn't fit elsewhere yet. |

## Adding a resource

Add a row to the topic's table:

```markdown
| [Resource name](https://link) | Course | Beginner | To do | Why it's useful |
```

- **Type:** Course · Book · Article · Video · Podcast · Tool · Docs · Repo
- **Level:** Beginner · Intermediate · Advanced
- **Status:** To do · In progress · Done · Reference

To add a new topic, create a folder with a `README.md` using the same table and list it above.
