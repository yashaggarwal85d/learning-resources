- **Monomorphization**: the compiler writing out a generic function's body again, once per concrete type it is actually called with, before it ever optimizes anything. *Where you meet it:* `fn encode_generic<C: Codec>(c: &C) -> u8` called with both a codec `A` and a codec `B`.
- **Zero-overhead (zero run-time cost)**: a monomorphized call runs exactly as fast as a hand-written, non-generic call, because by run time there is no generic code left at all. *Where you meet it:* the claim this whole topic tests, then qualifies.
- **Monomorphization bloat**: the compile-time and binary-size cost monomorphization moves the price to, growing with the number of distinct concrete types a generic function is actually instantiated with. *Where you meet it:* two compiled copies of `encode_generic`, one per codec, where a non-generic function would have had only one.
- **Outlining (the non-generic-inner-function trick)**: pulling a generic function's bulk logic into a separate, non-generic function, so only a thin generic shim gets duplicated per type. *Where you meet it:* `encode`'s byte-formatting loop moved into its own `format_bytes` function.
- **`impl Trait` (argument position)**: sugar for an anonymous generic parameter bound by `Trait`; the caller picks the concrete type, and two such parameters may pick different ones. *Where you meet it:* `fn two_impl_trait(a: impl Greet, b: impl Greet)`.
- **`impl Trait` (return position)**: the function itself picks one concrete, hidden type that implements `Trait`, and every return path must commit to that same type. *Where you meet it:* `fn make_adder_impl_trait(n: i32) -> impl Fn(i32) -> i32`.
- **Trait bound (named generic parameter)**: a single type parameter shared across every position it appears in, forcing them all to the same concrete type. *Where you meet it:* `fn two_same_type<T: Greet>(a: T, b: T)`, which rejects a `Dog` paired with a `Cat`.
- **`Box<dyn Fn>`**: the pre-`impl Trait` way to return "some closure" without naming its type, at the cost of one heap allocation per call. *Where you meet it:* `fn make_adder_boxed(n: i32) -> Box<dyn Fn(i32) -> i32>`.
