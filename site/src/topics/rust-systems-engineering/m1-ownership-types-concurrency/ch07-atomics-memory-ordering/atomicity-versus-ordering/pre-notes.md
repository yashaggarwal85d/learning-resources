- **`fetch_add`**: an atomic read-modify-write operation that adds to a location and returns its previous value, all as one indivisible step. *Where you meet it:* the eight-thread counter example.
- **Interleaving**: one particular order in which several threads' individual operations could have executed relative to each other. *Where you meet it:* what `loom` actually explores, exhaustively, instead of hoping one happens on a real run.
- **Model checking**: proving a property holds (or finding a counterexample) by systematically exploring every reachable state of a system, rather than sampling a few runs. *Where you meet it:* `loom`, used to find the relaxed-ordering violation for real.
- **Undefined behavior (UB)**: a condition the language specification says must never occur; once it does, the compiler is permitted to assume it didn't and optimize on that assumption, with no guaranteed resulting behavior at all. *Where you meet it:* why a data race is worse than "the wrong answer."
- **C++20**: the 2020 revision of the C++ standard, whose atomics and memory-ordering model Rust's `std::sync::atomic` module explicitly follows. *Where you meet it:* why Rust's four orderings (`Relaxed`, `Release`, `Acquire`, `SeqCst`) aren't a Rust-specific invention.
- **LKMM**: the Linux kernel's own memory model, maintained separately from (and in places stricter than) the model this topic covers. *Where you meet it:* named and explicitly deferred, not built here.
