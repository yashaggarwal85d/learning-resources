- **Self-describing page format**: a fixed-size page carries its own identity in its header — a magic number, a format version, a checksum, a page LSN — so it can be checked without any outside context. *Where you meet it:* a single flipped byte, caught by the page's own checksum, with nothing outside the page saying where to look.
- **Checksum vs magic number**: a checksum catches accidental damage to bytes that were supposed to stay the same; it can't catch a deliberate, consistent change, since that change still has a valid checksum of its own. Only a separate check of the magic number and format version catches that.
- **Explicit byte order**: a page's own multi-byte fields are written in one chosen order on purpose, never left to whatever the reading platform happens to use — read the same bytes the wrong way, and they mean something else entirely.
- **Item-identifier permanence**: an item's slot inside a page is never moved until it's freed, so that slot can be used as a stable, long-term reference even while the item itself gets physically shuffled around the page.
