- **PyObject**: the common header every Python object carries (a reference count and a type pointer) before any of its own value. *Where you meet it:* the lab's own byte-for-byte count of a boxed integer's overhead.
- **Boxed value**: a value wrapped in its own full object, as every plain Python `int`/`float`/etc. always is. *Where you meet it:* a list of boxed ints measured against the identical values packed into a native buffer.
- **__slots__**: a class declaration that removes a plain instance's own per-instance dictionary, storing its named attributes directly instead. *Where you meet it:* the lab's own measured instance, with and without one.
- **Specializing, adaptive interpreter**: an interpreter that rewrites a line's own bytecode to a type-specific version once it sees what actually shows up, and rewrites it again if that changes. *Where you meet it:* the same function disassembled cold, then warm for two different argument types.
- **Mis-specialization**: the cost paid when a specialized instruction's assumption turns out wrong and has to adapt again. *Where you meet it:* a function called with a genuine mix of int and float arguments instead of one consistent type.
- **JIT (just-in-time) compiler**: a compiler that turns hot, already-specialized bytecode into real machine code while the program runs, rather than ahead of time. *Where you meet it:* checked directly against this sandbox's own build, which doesn't have it enabled.
- **Vectorized call**: a single call that runs the same operation over a whole buffer of values at once, rather than one Python-level step per value. *Where you meet it:* the lab's own measured speedup over an equivalent per-row loop.
