- **Record validator**: a declared shape for one record that coerces what it safely can and raises a structured error naming the exact field it can't. *Where you meet it:* the first two reveals, including the real scaling measurement.
- **DataFrame schema**: a declared shape for a whole table's columns, checked once against the entire table rather than field by field. *Where you meet it:* the predict step and both DataFrame reveals, the center of this topic's cross-backend claim.
- **Row-level vs. batch-level cost**: the same check run once per value inside a loop, versus run once as a single operation across an entire column. *Where you meet it:* the row-vs-batch reveal, measured directly rather than assumed.
- **Production-scale data-quality scan**: a framework that checks data that's already landed, in a running deployment, rather than at the moment it first arrives. *Where you meet it:* the one reveal this topic names honestly rather than runs.
- **Governance tooling**: an organization-wide layer that audits and catalogs data quality downstream of where it was first validated. *Where you meet it:* the "Prove it" scenario's second failure, and this topic's own handoff.
