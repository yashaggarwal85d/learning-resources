- **PyO3 extension**: a Python module whose actual logic is written in Rust and compiled, loaded by an ordinary `import` like any other module. *Where you meet it:* the extension-builds reveal and the three-way speed comparison, the center of this topic's "Rust underneath" claim.
- **The GIL (Global Interpreter Lock)**: the one lock that normally stops two pieces of Python bytecode from running at the same instant, even across threads. *Where you meet it:* the predict step and the GIL-released reveal, measured directly rather than argued.
- **`py.allow_threads`**: PyO3's own mechanism for a Rust extension to explicitly drop that lock for the duration of a call. *Where you meet it:* the GIL-released reveal's real counter measurement.
- **abi3 / the limited API**: a feature flag that builds one wheel against a stable subset of the Python C API, working unmodified across a whole range of future versions instead of just one. *Where you meet it:* the abi3 reveal and the "Prove it" scenario, the real two-wheel comparison.
- **Free-threaded CPython**: an optional interpreter build, starting in Python 3.13, that can remove the GIL entirely — checkable directly rather than assumed from a version number. *Where you meet it:* the final reveal, this sandbox's own honestly disclosed limit.
