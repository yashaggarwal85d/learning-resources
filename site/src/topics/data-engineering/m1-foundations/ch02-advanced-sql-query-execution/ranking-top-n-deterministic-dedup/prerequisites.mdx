### <span class="n">00</span> The terms this topic uses

A few words, each defined in full inside the reel; this is just so they are not a surprise.

- **`ROW_NUMBER`/`RANK`/`DENSE_RANK`** — three ways to number rows within a partition, differing only in how they handle ties.
- **Tie-breaker** — an extra, guaranteed-unique `ORDER BY` column added purely to make a ranking's output deterministic.
- **`QUALIFY`** — a clause (not in PostgreSQL) that filters on a window function's result directly, instead of staging it through a subquery/CTE.

<p class="check"><b>Check yourself:</b> if three rows tie for the top amount, what does RANK() assign to the next, fourth-highest row? (Answer: four — RANK leaves gaps, so three rows tied at rank one are followed by rank four, not rank two.)</p>
