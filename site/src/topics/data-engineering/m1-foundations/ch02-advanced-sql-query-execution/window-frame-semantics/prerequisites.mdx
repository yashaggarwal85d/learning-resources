<section class="prereq" data-section="basics">

### <span class="n">00</span> The terms this topic uses

A few words, each defined in full inside the reel; this is just so they are not a surprise.

- **Partition** — the group of rows (set by `PARTITION BY`) a window function processes together, without collapsing them into one row.
- **Peer group** — the set of rows tied on the window's `ORDER BY` expression.
- **Frame** — the specific subset of the current partition a frame-sensitive window function reads for a given row; set by `ROWS`/`RANGE`/`GROUPS`.
- **`EXCLUDE`** — a frame modifier that drops the current row and/or its peers from an otherwise-included frame.

<p class="check"><b>Check yourself:</b> with no explicit frame, does <code>SUM(amount) OVER (ORDER BY event_time)</code> give two rows with the exact same event_time two different running totals? (Answer: no — the default RANGE frame extends through every peer of the current row, so tied rows get the identical total, including both of their amounts.)</p>
