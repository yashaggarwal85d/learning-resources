### <span class="n">00</span> The terms this topic uses

A few words, each defined in full inside the reel; this is just so they are not a surprise.

- **`LAG`/`LEAD`** — window functions that read a value from a previous/next row of the same partition.
- **Island** — a maximal run of contiguous rows satisfying some condition (or within one time-gap threshold of each other).
- **Row-number-difference trick** — subtracting a filtered row-number from an unfiltered one to get a constant-within-island grouping key.
- **Sessionization** — splitting an event stream into episodes using an inactivity threshold.

<p class="check"><b>Check yourself:</b> what does LAG(event_time) return for the very first row of a customer's history? (Answer: NULL — there is no previous row in that partition, which is exactly the signal used to flag the start of a new session.)</p>
