- **Stage boundary**: the point in a distributed plan where a shuffle splits it into two sequential pieces, so the second piece can only start once the first has actually finished. *Where you meet it:* the moment this topic's whole re-optimization story hinges on.
- **Shuffle partition**: one of the pieces data gets split into when it's redistributed by a hash function during a shuffle. *Where you meet it:* this topic's own coalescing measurement, 200 configured down to 1 real one.
- **Broadcast threshold**: the size limit under which an engine will copy a join side whole to every node, rather than redistribute both sides (introduced in topic 25). *Where you meet it:* the number AQE re-checks once a side's real size is known.
- **Bloom filter**: a compact structure that can say "definitely not a member" for certain, and "maybe a member" otherwise — never a false "no", sometimes a false "maybe". *Where you meet it:* Spark's own runtime filter, built from a join's smaller side.
