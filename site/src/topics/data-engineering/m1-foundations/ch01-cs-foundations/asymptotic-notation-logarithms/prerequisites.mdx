### <span class="n">01</span> High-school algebra: powers and roots

b<sup>k</sup> means k factors of b, so 10<sup>9</sup> is a billion and 1,000<sup>3</sup> is the same billion. A logarithm undoes a power: log<sub>b</sub> x = k means b<sup>k</sup> = x. That is all the reel assumes; the change of base is taught in the reel itself.

<p class="check"><b>Check yourself:</b> what is 2<sup>10</sup>? (Answer: 1,024, close to a thousand. That near-coincidence is why a billion takes about 30 halvings.)</p>

### <span class="n">02</span> The four refreshers before this one

Python, Git, the shell and the delivery workflow. This reel leans on one thing from them: Git bisect halves a range of commits at every test, which is the same halving that a logarithm counts. The reel also mentions code review, CI and tests as the checks that say a change is right.

<p class="check"><b>Check yourself:</b> about how many tests does Git bisect need to find one bad commit among 1,000? (Answer: about 10, because each test halves the range.)</p>
