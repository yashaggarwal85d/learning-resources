This is a refresher, the fourth of five. It builds on the three before it: the Python you write, the Git history you change and the shell commands a CI job runs. ### <span class="n">01</span> Python functions and decorators

The tests in this reel are plain functions, and the test runner's two main tools, <code>@pytest.mark.parametrize</code> and <code>@pytest.fixture</code>, are decorators. The Python refresher covers both.

<p class="check"><b>Check yourself:</b> what does <code>@timed</code> above <code>def load</code> mean? (Answer: <code>load = timed(load)</code>: a function that takes a function and returns a new one.)</p>

### <span class="n">02</span> Pull requests and a bisect oracle

A pull request is a proposed branch that teammates review before it lands on the main branch. The Git refresher shows three ways it can land, and uses a failing test as the oracle that <code>git bisect</code> trusts. This topic turns that oracle into a unit test and puts it in front of the merge button.

<p class="check"><b>Check yourself:</b> what must a bisect oracle exit with for a good commit, and for a bad one? (Answer: 0 for good; 1 to 127, except 125, for bad. 125 means skip.)</p>

### <span class="n">03</span> Exit status and pipelines

A CI job is a chain of shell commands, and each command ends with a number: 0 means success. A pipeline reports the status of its last command unless <code>pipefail</code> is on. The shell refresher explains where those numbers come from; the CI step in this reel is that idea on a runner.

<p class="check"><b>Check yourself:</b> <code>jq -r .status missing.jsonl | sort | uniq -c</code>, with <code>jq</code> failing: what is the pipeline's status in a plain bash script? (Answer: 0, the status of <code>uniq</code>; with <code>set -o pipefail</code> it is jq's 2.)</p>

### <span class="n">04</span> Installing packages with pip

<code>pip install -r requirements.txt</code> installs whatever the file lists, choosing for each line the newest version that matches. <code>pip freeze</code> prints what is installed, every package pinned with <code>==</code>. The last two steps of the reel are about what that file should say.

<p class="check"><b>Check yourself:</b> what does <code>pip freeze</code> print? (Answer: every installed package, dependencies included, as <code>name==version</code>.)</p>
