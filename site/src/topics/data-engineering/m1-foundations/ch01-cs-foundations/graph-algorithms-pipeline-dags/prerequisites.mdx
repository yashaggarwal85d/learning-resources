### <span class="n">00</span> Basics: words the reel takes for granted

- **Graph, vertex, edge**: a graph is a set of vertices (things) joined by edges (relationships). *Where you meet it:* a road map, a social network, or a list of which task depends on which.
- **Directed vs undirected edge**: a directed edge is an arrow from one vertex to another; an undirected edge joins two vertices with no direction. *Where you meet it:* "follows" on a social network is directed, "friends" is not.
- **Path**: a sequence of vertices where each is joined to the next by an edge. *Where you meet it:* a route from one city to another through intermediate stops.
- **Queue**: a first-in, first-out list: the oldest item leaves first. *Where you meet it:* a print queue, or Python's `collections.deque`.
- **O(V + E)**: a cost that grows with the number of vertices plus the number of edges. *Where you meet it:* "a traversal visits every vertex and edge once" is O(V + E).

### <span class="n">01</span> Graph vocabulary: vertices, edges, directed vs undirected

You should be comfortable with vertices and edges, directed vs undirected graphs, degree, paths and cycles, and the idea that a graph can be stored as an adjacency list or a matrix. This reel does not prove graph theorems; it applies six algorithms. If the vocabulary above read cleanly, you are ready.

<p class="check"><b>Check yourself:</b> why is an adjacency list, not a matrix, the natural store for a pipeline graph? (Answer: pipelines are sparse — the number of edges is close to the number of tasks, not its square — so a list is linear space while a matrix is quadratic.)</p>

### <span class="n">02</span> Big-O, to read O(V + E)

Every algorithm here costs **O(V + E)**: linear in the number of tasks plus the number of dependencies. You only need to read that bound — big-O describes how a cost grows with input size, dropping constant factors — not to derive it. If "linear in the size of the graph" means something to you, that's enough.

<p class="check"><b>Check yourself:</b> a pipeline doubles its tasks and its dependencies. Roughly what happens to an O(V + E) traversal's running time? (Answer: it roughly doubles.)</p>
