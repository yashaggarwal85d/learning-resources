### <span class="n">02</span> Exit status, as bisect reads it

Every command ends with a number, its exit status, and 0 means success. The Git refresher met it through <code>git bisect run</code>, which treats 0 as good and 1 to 127 (except 125) as bad. This topic starts from there and shows where those numbers come from.

<p class="check"><b>Check yourself:</b> which exit status means a test could not be run, so bisect should skip the commit? (Answer: 125.)</p>

### <span class="n">03</span> A host, a port and a connection

Two steps of the reel mention them: a hung job waits on a connection to a database, and an ssh tunnel forwards one port to another. A server listens on a numbered port on a host (PostgreSQL on 5432), a client connects to it, and a socket is a program's end of that connection. You need only that picture here; the networking topics later in this chapter build it out.

<p class="check"><b>Check yourself:</b> a program asks to connect to <code>db.internal:5432</code>. Which part names the machine and which names the program on it? (Answer: <code>db.internal</code> is the host; port 5432 picks the program listening there, PostgreSQL by convention.)</p>
