# Fact-check: Linux shell and process toolkit

Every claim in this topic's plan (`OUTLINE.md`, its claims list 1–60 and every number the reel shows), checked against primary sources on 11 October 2026. Corrections were applied to `OUTLINE.md` the same day, and the quotes they rest on were added to `SOURCES.md` (`node scripts/sources.mjs check` passes 181 quotes, 0 problems). Each source was read as raw fetched text (`scripts/sources.mjs fetch`, or `curl` for source code), never through a summarising tool.

Behaviour was re-run in the sandbox: Linux 6.18.44, Bash 5.2.21, dash 0.5.12, jq 1.7, mawk 1.3.4, GNU sed 4.9, grep 3.11, coreutils 9.4, diffutils 3.10, strace 6.8, procps-ng 4.0.4, util-linux `setpriv`/`flock`, Python 3.11.17, tzdata 2026c, running as root (non-root cases through `setpriv --reuid=65534 --regid=65534 --clear-groups`). The data file was regenerated to the plan's construction (10,000 events, 40 dirty spellings).

**Current versions (checked 11 October 2026):** Bash 5.3 (ftp.gnu.org; manual "Edition 5.3, last updated 18 May 2025"); POSIX.1-2024 (Issue 8); Linux man-pages 6.19 (kernel.org; Debian serves `_exit(2)` from 6.18-1); procps-ng 4.0.7; strace 7.2 (NEWS: "release 7.2 (2026-08-18)"); **jq 1.8.2** (the manual is "jq 1.8"); gawk 5.4.1 (manual Edition 5.4); GNU sed 4.10; grep 3.12; **coreutils 9.12** (the Debian pages quoted are 9.10); **diffutils 3.12**; util-linux 2.42.4 (Debian); Debian cron 3.0pl1-211; OpenBSD-current `ssh(1)` dated September 5, 2026 (portable OpenSSH 10.6); Git 2.56.0.
