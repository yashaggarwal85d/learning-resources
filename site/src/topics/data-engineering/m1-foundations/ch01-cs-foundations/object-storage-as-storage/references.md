Last verified against these sources: 2026-10-13.

- Amazon S3 User Guide, [Amazon S3 data consistency model and features](https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html) (strong read-after-write consistency for PUT/DELETE in all regions; single-key atomicity; LIST read-after-write; bucket configuration is eventually consistent).
- AWS, [Amazon S3 now delivers strong read-after-write consistency automatically for all applications](https://aws.amazon.com/about-aws/whats-new/2020/12/amazon-s3-now-delivers-strong-read-after-write-consistency-automatically-for-all-applications/) (December 2020).
- Amazon S3 User Guide, [Best practices design patterns: optimizing Amazon S3 performance](https://docs.aws.amazon.com/AmazonS3/latest/userguide/optimizing-performance.html) (at least 3,500 PUT/COPY/POST/DELETE or 5,500 GET/HEAD requests per second per partitioned prefix; no limit on prefixes; 503 Slow Down; consistent small-object and first-byte latencies of roughly 100–200 ms).
- Amazon S3 User Guide, [Performance guidelines for Amazon S3](https://docs.aws.amazon.com/AmazonS3/latest/userguide/optimizing-performance-guidelines.html) (scale connections horizontally; use byte-range fetches; GET aligned to multipart part boundaries; retry slow requests).
- AWS whitepaper, *Best Practices Design Patterns: Optimizing Amazon S3 Performance* (2019) — ≈ 85–90 MB/s per request, and 8 MB or 16 MB typical byte-range sizes (the figures the chapter's canonical table and the held I/O cost model use).
- Amazon S3 User Guide, [Amazon S3 multipart upload limits](https://docs.aws.amazon.com/AmazonS3/latest/userguide/qfacts.html) (maximum object size 48.8 TiB; up to 10,000 parts; part size 5 MiB–5 GiB with no minimum on the last part; consider multipart around 100 MB).
- Amazon S3 User Guide, [Add preconditions to S3 operations with conditional requests](https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-requests.html) (conditional writes on PutObject, CompleteMultipartUpload and CopyObject; prevent overwrite with `If-None-Match`; guard with `If-Match`; no extra charge).
- AWS, [Amazon S3 conditional writes](https://aws.amazon.com/about-aws/whats-new/2024/08/amazon-s3-conditional-writes/) (`If-None-Match`, August 2024) and [conditional write with `If-Match`](https://aws.amazon.com/about-aws/whats-new/2024/11/amazon-s3-functionality-conditional-writes/) (November 2024).
- Amazon S3 User Guide, [Appending data to objects in directory buckets](https://docs.aws.amazon.com/AmazonS3/latest/userguide/directory-buckets-objects-append.html) and [Renaming objects in directory buckets](https://docs.aws.amazon.com/AmazonS3/latest/userguide/directory-buckets-objects-rename.html) (S3 Express One Zone append and atomic `RenameObject`).
- Google Cloud Storage docs, [Consistency](https://cloud.google.com/storage/docs/consistency) (strongly consistent object read-after-write and bucket/object listing; some IAM operations eventually consistent) and [Request rate and access distribution guidelines](https://cloud.google.com/storage/docs/request-rate) (≈ 1,000 writes/s and 5,000 reads/s baseline; ramp up gradually; avoid sequential-key hotspotting).
- D. Durner, V. Leis and T. Neumann, "Exploiting Cloud Object Storage for High-Performance Analytics", *PVLDB* 16(11), 2023, pp. 2769–2782. [vldb.org](https://www.vldb.org/pvldb/vol16/p2769-durner.pdf)
