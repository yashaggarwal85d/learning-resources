- **SCD Type 2**: a dimension-change strategy that adds a new row with a new surrogate key for each version, leaving every earlier row untouched. *Where you meet it:* a customer's address history kept as several rows, each tagged with when it was the true current address.
- **Effective/expiry timestamp**: the pair of columns on an SCD Type 2 row marking exactly when that version started and stopped being true. *Where you meet it:* an `effective_ts`/`expiry_ts` pair used to answer "what was true on this date" with a simple range check.
- **Hash-diff change detection**: comparing one hash of every tracked column at once, instead of comparing each column individually, to decide whether a row has genuinely changed. *Where you meet it:* a single `address_hash` column that flags a change the moment it differs, with no per-column comparison code to maintain.
- **Idempotent MERGE load**: a load built so that running it again with the same input changes nothing. *Where you meet it:* re-running an SCD2 load after a crash or a retry, with the assurance it won't duplicate anything that already landed.
