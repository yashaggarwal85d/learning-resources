- **Bytes-scanned billing**: a query-compute pricing model that charges for how much data a query reads, regardless of how long the query takes to run. *Where you meet it:* BigQuery's on-demand pricing, contrasted against flat-rate/capacity pricing's opposite axis.
- **Hive-partitioned layout**: splitting a dataset into separate files or directories by a column's value (such as month), so a query filtered on that column can skip files that can't match. *Where you meet it:* the measured cause of both the narrow query's win and the broad query's loss.
- **Storage class**: a tier of object storage that trades slower retrieval latency for a lower price to store the same bytes. *Where you meet it:* one of object storage's several independent billing axes.
- **File-footer overhead**: the metadata every Parquet (or Iceberg) file carries about its own contents, read once per file opened. *Where you meet it:* why many small files cost more to scan broadly than one large file holding the same rows.
