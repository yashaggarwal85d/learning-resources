# Pre-notes: On-prem data platforms after Hadoop

- **HDFS.** The Hadoop Distributed File System: the storage layer of a decade-old on-prem data-platform estate.
- **YARN.** Hadoop's own resource-scheduling layer, allocating cluster compute across jobs on that same estate.
- **Data gravity.** The tendency for processing to move toward where data already sits, because moving the data itself is costly.
- **Private cloud.** An organisation's own infrastructure, run and operated by that organisation rather than a public-cloud vendor, but built on cloud-like orchestration and self-service patterns.
- **On-prem operational cost.** The costs a cloud vendor otherwise absorbs: hardware refresh cycles, running Kubernetes and the object store yourself, and capacity planning without autoscaling's safety net.
