- **Catalog**: the system of record for a table's metadata, schema and access policy, separate from the files it describes. *Where you meet it:* Lake Formation, Unity Catalog, BigLake metastore, Polaris, OneLake.
- **Credential vending**: a catalog handing a trusted engine a temporary, down-scoped storage credential instead of letting it hold a standing, bucket-wide key. *Where you meet it:* AWS's own four-step Lake Formation flow, the Iceberg REST spec's `storage-credentials` field.
- **Row filter**: a predicate silently appended to every query from a given principal, restricting which rows it can see. *Where you meet it:* Postgres row-level security, BigQuery row-level security, Lake Formation row filters.
- **Column mask**: a function applied to a column's value before it reaches a given principal, typically redacting or nulling it. *Where you meet it:* a security-invoker Postgres view, BigQuery data masking, Unity Catalog column masks.
- **Bypass failure mode**: an engine that reaches storage through a credential that never goes through the catalog's own check, so every policy the catalog holds simply never applies to that engine's reads. *Where you meet it:* a role with `BYPASSRLS`, an engine handed the bucket's own bulk IAM role.
- **Tag-based grant**: a grant attached to a key-value attribute on a resource rather than to the object itself, so a new object that inherits the tag inherits the grant automatically. *Where you meet it:* Lake Formation LF-Tags.
