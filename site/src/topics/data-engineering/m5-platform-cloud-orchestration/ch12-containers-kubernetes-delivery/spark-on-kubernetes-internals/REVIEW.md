## Sandbox disclosure

No local Kubernetes cluster exists on this build machine: `docker ps` fails ("no such file or directory" on the daemon socket — the `docker` CLI is present but nothing is listening), and there is no `kubectl`, `kind`, or `k3s`. This topic hosts the chapter's §12.2 lab (run Spark on a local cluster, inject executor-pod eviction/`OOMKilled`/PVC failure/spot-style node loss with decommissioning off and on, record recovery times); that lab's actual pod-level timings could not be run and are sourced from Spark's and AWS's own documentation instead, disclosed as such in post-notes.md's "Try it" section. What is run for real in `examples.py`: the `OwnerReference` cleanup model, the shuffle-tracking-timeout model, and the decommission-vs-abrupt-kill recompute-cost model, including the two-minute Spot-interruption window AWS documents — all built strictly from the sourced mechanics.
