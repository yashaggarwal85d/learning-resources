## DataHub — What is DataHub? (Concepts)

URL: https://docs.datahub.com/docs/what-is-datahub/datahub-concepts

> An entity is the primary node in the metadata graph.

> An aspect is a collection of attributes that describes a particular facet of an entity.

> A relationship represents a named edge between 2 entities.

## OpenMetadata — High Level Design

URL: https://docs.open-metadata.org/latest/main-concepts/high-level-design

> The core API, unifying and centralising the communication with internal and external systems.

> The UI for a team-centric metadata Serving Layer.

> The Ingestion Framework as an Interface between OpenMetadata and external sources.
