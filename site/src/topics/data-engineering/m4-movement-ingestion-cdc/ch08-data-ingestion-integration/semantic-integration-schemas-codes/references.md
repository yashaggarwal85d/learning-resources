Last verified: 1 November 2026. The slowly changing crosswalk, the dated-exchange-rate
conversion, the DST-transition comparison, and the mapping test (`examples.py`) are direct runs
against this sandbox's own real PostgreSQL 16 cluster. Rahm and Bernstein's own schema-matching
taxonomy is named from secondary summaries rather than quoted, since the paper itself sits
behind a sign-in wall (link.springer.com redirects to institutional sign-in) and its own
secondary mirror refused a direct fetch on a certificate mismatch — confirming CHAPTER.md's own
plan-time note that the PDF route returned HTTP 404. ISO 4217 is read via Wikipedia since
iso.org itself returned HTTP 403 to a direct fetch.

- UCUM, The Unified Code for Units of Measure: [ucum.org](https://ucum.org/ucum). Unambiguous unit strings, each mapped to one semantic element.
- Wikipedia, ISO 4217: [en.wikipedia.org](https://en.wikipedia.org/wiki/ISO_4217). Currency codes and the minor-unit concept.
- IANA, Time Zone Database: [iana.org](https://www.iana.org/time-zones). What the database holds, and that it changes.
- PostgreSQL 18 docs, Date/Time Functions and Operators: [postgresql.org](https://www.postgresql.org/docs/18/functions-datetime.html). The AT TIME ZONE operator this topic's own lab uses directly.
- Rahm and Bernstein, "A survey of approaches to automatic schema matching" (*The VLDB Journal*, 2001): [link.springer.com](https://link.springer.com/article/10.1007/s007780100057). Named only; the paper itself is not reachable.
