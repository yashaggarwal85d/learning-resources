- **Schema mapping**: a transformation that makes one system's attributes line up with
  another's, written by matching names, types and sample values across the two.
- **Crosswalk**: a table that maps one system's own codes to another's, carrying the validity
  window a mapping holds for, since the mapping itself can change over time.
- **Reference data**: the lookup values (codes, categories, units) a fact table's own columns
  point to, rather than the fact's own measurements.
- **ISO 4217**: the standard that assigns every currency a code and a minor-unit exponent, the
  number of decimal places that currency's smallest subdivision actually represents.
- **UCUM**: the Unified Code for Units of Measure, a specification that gives every unit string
  exactly one meaning a machine can check.
- **Time zone database**: the IANA-maintained rule set mapping a named zone to its own history
  of local-time offsets, updated whenever a political body changes a time zone's own rules.
- **UTC instant**: the single, zone-independent moment in time a timestamp actually refers to,
  stored alongside the original local value and zone rather than in place of them.
