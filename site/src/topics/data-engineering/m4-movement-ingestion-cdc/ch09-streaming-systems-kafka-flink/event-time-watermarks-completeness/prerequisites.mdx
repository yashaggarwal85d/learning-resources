### <span class="n">01</span> Before this: delivery semantics vocabulary

This topic leans on the delivery-semantics vocabulary already built — at-least/at-most/exactly-
once as statements about effects, not deliveries — since a watermark's own "no more data before
T" claim is the same kind of honest, named statement applied to completeness instead of delivery.
If that's unfamiliar, start with
[Delivery semantics and where duplicates arise](../delivery-semantics-duplicates/) first.
