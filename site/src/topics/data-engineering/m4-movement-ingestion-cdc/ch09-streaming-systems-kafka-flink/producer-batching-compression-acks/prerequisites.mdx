### <span class="n">01</span> Before this: partitioned log storage

This topic uses the previous topic's vocabulary — a partition as a directory of segment files,
with an offset as the consumer's own single integer — without re-teaching it. If segments,
offsets or the sparse index are unfamiliar, start with
[Partitioned log storage: segments and indexes](../partitioned-log-segments-indexes/) first.
