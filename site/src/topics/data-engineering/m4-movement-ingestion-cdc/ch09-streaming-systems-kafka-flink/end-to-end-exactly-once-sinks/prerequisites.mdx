### <span class="n">01</span> Before this: Kafka transactions, and atomic offset-output commits

This topic builds on Kafka's own transaction mechanism and the atomic offset-with-output
pattern it established, extending both to a sink outside Kafka. If Kafka transactions are
unfamiliar, start with
[Kafka transactions and read-committed](../kafka-transactions-read-committed/) first. The
companion idempotent-extraction concept from Chapter 8 (`checkpoint-output-atomicity`,
`exactly-once-effect-recipe`) is used by name, not retaught here.
