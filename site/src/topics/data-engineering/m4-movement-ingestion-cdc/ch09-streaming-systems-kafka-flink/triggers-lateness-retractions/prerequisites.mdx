### <span class="n">01</span> Before this: windowing and pane state

A window's pane is what a trigger fires against, and this topic's allowed-lateness reveal leans
directly on the pane-cleanup mechanics from the prior topic — a late record can only be applied
if the pane it belongs to hasn't closed yet. If that's unfamiliar, start with
[Windowing: tumbling, sliding, session, global](../windowing-tumbling-sliding-session/) first.
