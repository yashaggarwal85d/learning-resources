### <span class="n">01</span> Before this: tiered storage, exactly-once sinks, and dedup

A replay's backfill source is either the hot log or the tiered storage this chapter already
covered; a replay is only safe to repeat using the same idempotent-sink and dedup machinery
already built for exactly-once sinks and deduplication. Raw/bronze landing-layer design (Chapter
8) is the other possible backfill source once Kafka itself no longer has the data, named here but
not retaught. If these are unfamiliar, start with
[Kafka tiered storage](../kafka-tiered-storage/),
[End-to-end exactly-once with external sinks](../end-to-end-exactly-once-sinks/), and
[Deduplication keys and idempotent consumers](../deduplication-idempotent-consumers/) first.
