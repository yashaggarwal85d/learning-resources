### <span class="n">01</span> Before this: event time, watermarks and completeness

A window is the chunk of time a watermark's completeness claim gets applied to, and this topic's
pane-cleanup reveal leans directly on the watermark (plus allowed lateness) as the bound that
decides when a pane's state can be dropped. If that's unfamiliar, start with
[Event time, watermarks and completeness](../event-time-watermarks-completeness/) first.
