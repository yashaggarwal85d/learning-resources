## Red team

- **Is killing a raw socket before the client library sends its PUBACK a fair way to produce QoS 1's documented duplicate, or does it overstate what the specification guarantees?** It's fair: the specification's at-least-once guarantee is exactly that the broker redelivers anything it never got acknowledged, and killing the socket before the ack is sent is a real, reproducible instance of "the connection died before delivery completed," not a contrived edge case. The experiment was run twice end-to-end and produced byte-identical counts both times.
- **Does citing the Sparkplug B Protobuf schema from the Eclipse Tahu reference implementation (not the ISO page itself) overstate the ISO/IEC 20237:2023 claim?** No — the schema and the message-flow rules (NBIRTH completeness, sequence wrap, bdSeq, rebirth) are quoted from the Eclipse Sparkplug 3.0.0 specification PDF itself, fetched directly; the ISO page, which would only confirm the ISO catalogue designation, returned HTTP 403 in this sandbox and is disclosed as unreachable in `SOURCES.md` rather than asserted from memory.
- **Is the Unified Namespace write-up (HiveMQ) treated as normative when CHAPTER.md says it isn't?** No — `OUTLINE.md` and `SOURCES.md` both label it a secondary, vendor-community description, and the topic's own claims about the UNS (no history, no replay, retained-value-as-current-state) are backed independently by the MQTT specification's RETAIN semantics already quoted above, not by the HiveMQ page alone.
- **Does the dashboard-shows-211-for-twenty-minutes hook claim get verified or just narrated?** The retained-message mechanism it depends on (a late/reconnecting subscriber receiving the broker's last stored value, not a live reading) is the exact behaviour `demonstrate_retained_and_will` measures and asserts against a real broker; the twenty-minute figure itself is CHAPTER.md's own illustrative number, stated as a hook, not as a measured result.
- **Checked `reel.tsx`, `scenes.tsx`, `narration.json` for leaked exact phrasing from the quoted sources** — none found.
