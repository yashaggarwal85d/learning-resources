## Red team

- **Predict step 4** ("does looking a machine up in today's hierarchy answer a question about last quarter?"): the tempting wrong answer is "yes, because the hierarchy table is the source of truth for where a machine is" — tempting precisely because it's true *for a question about right now*. The correct answer holds even if the hierarchy table is updated the instant a machine moves (not merely delayed), because the table only has a `valid_from`/`valid_to`-aware join to answer a question about *any point in history other than now*. Strengthened the explain text to say this is true even with a perfectly up-to-date table, not only a stale one.
- **Predict step 9 (Prove it)**: edge case checked — if the cache refresh exactly coincided with the move and no reading ever straddled the gap, the bug wouldn't fire that particular day; the question is deliberately scoped to "a reading from three days ago", which is unambiguously before a daily-refreshed cache could have recorded a move that happened within that window. No counter-example survives within the stated scope.
- **Counter-example tried against step 6's claim**: could the roughly-31-percent figure be an artifact of the seeded random ranges rather than the join bug itself? No — the assertions pin the exact mechanism (`l4_understatement == press7_pre_move`, `l6_overstatement == press7_pre_move`), so the number is determined by press7's own pre-move total divided into L4's true total, not by the RNG's specific draws; a different seed would move the exact percentage but not the direction or the mechanism.
- **Checked against the next topic's syllabus line** (production entities and genealogy): no overlap — topic 1 never touches work orders, batches, recipes or lots.
- **ISA.org AI-ingestion ban (found 2026-10-31, while building topic 6 of this same chapter):** ISA's standards pages state a site-wide notice prohibiting AI tools from ingesting their content. This topic had fetched and quoted two isa.org pages verbatim (claims 1-5, above) before the notice was noticed. Corrected by removing every quote, naming both sources bibliographically, and keeping only the underlying factual claims as this topic's own stated content rather than as quoted ISA text. No other file in this topic (`reel.tsx`, `scenes.tsx`, `narration.json`) was found to echo ISA's exact phrasing, so no further files needed correction.
