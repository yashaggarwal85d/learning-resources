## Red team

- **Nelson's paper, re-checked**: a dedicated follow-up search (beyond the original research pass) specifically hunted for any PDF mirror, course page, ResearchGate copy, or author-site copy of the 1984 paper, and for any source quoting it verbatim with secure attribution. The only near-miss (SAS's own documentation) quotes phrases explicitly attributed to Nelson's separate **1985** JQT paper ("Interpreting Shewhart X̄ Control Charts"), not the 1984 "Technical Aids" column asked for here — confirmed by SAS's own text distinguishing "Nelson (1984, 1985)" while attributing the quoted sentences to the 1985 citation. Using that quote under the 1984 citation would misattribute it, so it is not used. The topic's `SOURCES.md` already disclosed the 1984 paper as unreachable before this re-check; this confirms the disclosure stands and closes the gap rather than leaving it open.
- **Predict step 4** (does adding zone rules ever cost anything?): the tempting wrong answer is "no, because the extra rules only watch for additional patterns, they don't change how the 3-sigma rule itself behaves." This is true of the 3-sigma rule *in isolation*, but the question asks about the *chart's* overall false-alarm rate, which is the union of every active rule's individual false alarms — adding any rule that can fire can only shorten the combined average run length, never lengthen it. Strengthened the explain text to state this as a logical consequence (a union of independent-ish rare events), not just an empirical finding.
- **Counter-example tried against the eighth-rule finding**: could the roughly-halved average run length be a seed artifact rather than a real property of combining all four rules? Re-ran the simulation with the module's rule-4 implementation checked by hand against a short synthetic run (`[1,1,1,1,1,1,1,1,0]` as a positive/negative mask) and confirmed `flag_rule4` correctly marks the eighth consecutive point and no earlier one; the magnitude of the ARL drop would move with a different seed, but the direction (adding a rule that can only add more trips shortens the run length) cannot reverse, by the same union argument as above.
- **Checked against topic 2's content** (production entities and lot genealogy): no overlap — topic 2 never touches inspections, control charts or capability indices; this topic's SQLite schema references `lot_id` by the same kind of key topic 2 used for lots, but does not re-model lot genealogy itself.
- **Checked against topic 4's planned content** (OEE): the quality factor in OEE is a count-based "good parts over total parts" ratio, never computed here; this topic's inspection-level, measurement-based quality data is a different grain, and the two are not conflated anywhere in the reel or the claims above.

No corrections required to `OUTLINE.md` beyond what is already reflected above (the Nelson re-check, already logged there as a chapter-plan change).
