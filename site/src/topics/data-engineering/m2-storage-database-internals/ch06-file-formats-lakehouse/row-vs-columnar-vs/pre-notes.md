- **A page**: the fixed-size unit a storage engine reads and writes as a whole, background from Chapter 5's own page material (§5.1). *Where you meet it:* the single unit this topic's point lookups and scans count as "touched" or not.
- **OLTP vs OLAP access patterns**: many small point lookups and writes versus large scans over few columns, background from Chapter 3's warehouse-vs-lake material. *Where you meet it:* the exact reason row storage and columnar storage each win a different one of these.
- **A cache miss**: a memory access that isn't found in a fast cache and has to be fetched from slower main memory, general computing background. *Where you meet it:* the reason this topic's byte-touched counts matter — fewer useless bytes read means fewer wasted cache lines.
- **A relation's attributes**: the named columns of a table, background from any prior exposure to tabular data. *Where you meet it:* the four attributes (`emp_id`, `dept_id`, `age`, `salary`) this topic's own packed-byte table is built from.
