- **A delimiter**: a character used to mark where one value ends and the next begins in a text file, background from any prior exposure to a text format. *Where you meet it:* the comma CSV splits fields on, which this topic shows isn't always safe to split on blindly.
- **Character encoding**: the mapping from bytes to the characters they represent, such as UTF-8, background from this course's own byte-level material. *Where you meet it:* the byte order mark this topic's own BOM trap depends on.
- **A parser**: software that reads a file's raw bytes and turns them into structured values a program can use, general background. *Where you meet it:* the different parsers (a naive split versus an RFC-conformant one, an exact integer parser versus a double-precision one) this topic compares directly.
- **Floating point / double precision**: a fixed-size binary representation of a number that can't hold every value exactly, background from general computing. *Where you meet it:* the JSON number that loses precision once a double-precision parser reads it.
