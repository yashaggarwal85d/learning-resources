- **Write-ahead log (WAL)**: a sequential, append-only log of every write, taught in topic 3 for a different engine (Postgres). *Where you meet it:* the crash-durability half of this topic's own write path, ahead of the memtable.
- **Skip list**: a sorted, linked data structure that supports fast search, insert and in-order scan, background from the Data Structures & Algorithms track. *Where you meet it:* RocksDB's own default memtable implementation, assumed rather than re-taught.
- **Sorted data structure / sorted run**: a collection of key-value pairs kept in key order, so a scan over it visits keys in order without re-sorting. *Where you meet it:* what every memtable and every file in this topic actually is.
- **Point lookup vs. range query**: a point lookup asks for one key's value; a range query asks for every key-value pair between two keys. *Where you meet it:* the two different read paths this topic contrasts directly.
- **Hash function / probabilistic structure**: a function mapping a key to a fixed-size value, used here to set and check individual bits rather than to look anything up directly. *Where you meet it:* what a Bloom filter actually is underneath.
- **Binary search**: searching a sorted sequence by repeatedly halving the range left to check, a standard algorithm assumed throughout. *Where you meet it:* what a file's own block index does to find one data block.
