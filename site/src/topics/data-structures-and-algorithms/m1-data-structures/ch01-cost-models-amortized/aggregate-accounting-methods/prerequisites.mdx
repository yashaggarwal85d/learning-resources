### <span class="n">01</span> Cost bounds and the machine they count

You can read O(1), Θ(n) and Θ(log n), you know the difference between a best, worst, average and expected case, and you accept that a step of the machine (here, writing one element) costs one unit. Topic 1 teaches the notation and the cases; topic 2 the machine.

<p class="check"><b>Check yourself:</b> an algorithm is O(n²) in the worst case and Θ(n) in the best case. Is it Θ(n²)? (Answer: no. Only its worst case is Θ(n²), if that bound is tight.)</p>

### <span class="n">02</span> Stacks

You know a stack holds items last in, first out: push adds on top, pop removes the top.

<p class="check"><b>Check yourself:</b> push a, push b, push c, then pop twice. What is left? (Answer: a.)</p>

<section class="prereq" data-section="binary">

### <span class="n">03</span> Binary counting

You can add 1 to a number written in binary: trailing 1s become 0s with a carry, and the next 0 becomes a 1.

<p class="check"><b>Check yourself:</b> what is 0111 + 1, and how many bits changed? (Answer: 1000; four.)</p>

</section>

<section class="prereq" data-section="series">

### <span class="n">04</span> Geometric series

You know that 1 + 2 + 4 + … + 2<sup>k</sup> = 2<sup>k+1</sup> − 1, and that 1 + 1/g + 1/g² + … = g/(g − 1) for g &gt; 1. The reel uses the first for doubling and the second for any growth factor.

<p class="check"><b>Check yourself:</b> what is 1 + 2 + 4 + 8 + 16? (Answer: 31.)</p>
