This is the first topic in Data Structures & Algorithms, and a refresher: it assumes you program comfortably and have met Big-O before. If you have not, start with the resources below; the reel is a recap, not a first course.

### <span class="n">01</span> Programming, loops and recursion

You can read a short loop or recursive function and say roughly how many times its body runs for an input of size n.

<p class="check"><b>Check yourself:</b> how many times does the inner statement run in <code>for i in range(n): for j in range(i): …</code>? (Answer: n(n − 1)/2.)</p>

### <span class="n">02</span> Logarithms, sums and limits

You know that log₂ n is the number of times you can halve n, that 1 + 2 + … + n = n(n + 1)/2, and what it means for a ratio to tend to 0 or to infinity.

<p class="check"><b>Check yourself:</b> roughly what is log₂ 1,000,000, and what does n / n² tend to? (Answer: about 20; it tends to 0.)</p>
