- "Adjacency list" (Wikipedia) — the list's own cost for neighbour-listing and edge-existence testing, and its own trade-off against the matrix. [source](https://en.wikipedia.org/wiki/Adjacency_list)
- "Adjacency matrix" (Wikipedia) — the matrix's own definition and its extension to multigraphs by storing an edge count per cell. [source](https://en.wikipedia.org/wiki/Adjacency_matrix)
- "Edge list" (Wikipedia) — the edge list's own definition and its Θ(E) space bound. [source](https://en.wikipedia.org/wiki/Edge_list)
- "Multigraph" (Wikipedia) — the formal definition of a graph permitting parallel edges, behind this topic's own multi-edge example. [source](https://en.wikipedia.org/wiki/Multigraph)
- "Directed acyclic graph" (Wikipedia) — the DAG definition this topic names, in both directions (no cycle; topologically orderable). [source](https://en.wikipedia.org/wiki/Directed_acyclic_graph)
- "Graph (abstract data type)" (Wikipedia) — a second, independent source for the list's and matrix's own shapes, and the matrix's own one-value-per-pair limit. [source](https://en.wikipedia.org/wiki/Graph_%28abstract_data_type%29)

Canonical numbers (the chapter's own graph: 6 vertices, 10 edges, 16 list entries, 36 matrix cells, the 250&times; crossover at 1,000 vertices) are computed and asserted in this topic's `examples.py`.
