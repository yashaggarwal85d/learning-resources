- **Hash function (one line).** A function that turns a key into a number, spreading unrelated
  keys apart as evenly as a coin flip would (Chapter 3).
- **Bit array.** A row of individually switchable on/off flags, addressed by position.
- **Probability of independent events.** When two events don't influence each other, the chance
  both happen is the product of each one's own chance.
- **Expected value.** The long-run average of a quantity across many repeated trials.
- **Natural logarithm and e (one line).** `e` is the number whose own growth rate always equals
  its current value; for a small `x`, `e^(−x)` is very close to `1 − x`.
- **False positive versus false negative.** A false positive says "maybe present" for something
  never stored; a false negative says "absent" for something that genuinely was stored.
- **Bits per key.** The amount of memory a structure spends, divided by the number of keys it
  holds — the one knob this topic's whole derivation turns.
