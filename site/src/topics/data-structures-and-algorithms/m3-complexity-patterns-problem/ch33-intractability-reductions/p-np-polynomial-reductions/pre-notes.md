- **Decision problem**: a question whose answer is only yes or no.
- **Polynomial time**: a cost bounded by a fixed power of the input's length; **exponential
  time**: a cost that grows like a constant raised to a power of the input's length.
- **Graph, with vertices and edges**: the object a reduction in this topic is drawn on.
- **Independent set and vertex cover**: a set of vertices with no edges between them, against a
  set of vertices that touches every edge.
- **Boolean formula in conjunctive normal form**: an AND of clauses, each an OR of variables and
  their negations.
- **Worst case**: the input that makes a procedure take the longest, not a typical one.
- **Brute force**: trying every candidate directly, with no shortcut.
