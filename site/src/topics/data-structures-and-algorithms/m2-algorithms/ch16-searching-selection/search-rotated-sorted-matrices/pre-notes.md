- **Rotation of an array** (one line): taking a sorted array and moving a prefix of it to the end, so `[0,1,2,4,5,6,7]` rotated at index 3 becomes `[4,5,6,7,0,1,2]`. *Where you meet it:* the structure every rotated-array search in this topic is built on.
- **Row-major order**: reading a 2-D grid one row at a time, left to right, then moving to the next row — the order a matrix is laid out in memory. *Where you meet it:* the one structural assumption that lets a flattened index reduce a matrix search to ordinary binary search.
- **Matrix indexing by a flattened index**: converting a single index `k` into a row and column, `row = k / cols` and `col = k % cols`, as if the whole 2-D grid were one long 1-D array. *Where you meet it:* how the row-major reduction turns a matrix search back into an array search.
- **Adversarial input**: an input constructed on purpose to force an algorithm's worst case, not one that arises naturally. *Where you meet it:* the near-all-duplicate array built specifically to make the rotated-array search degrade to a linear scan.
