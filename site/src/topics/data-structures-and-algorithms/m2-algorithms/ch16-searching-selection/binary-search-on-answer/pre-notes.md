- **Monotone function** (one line): a function whose output never decreases, or never increases, as its input grows. *Where you meet it:* the whole precondition behind every search in this topic — a feasibility check that never goes from true back to false as capacity grows.
- **Feasibility**: whether a candidate answer satisfies the constraints at all, without yet asking whether it's the best one. *Where you meet it:* "can these packages ship in this capacity" is a feasibility question; "what's the smallest capacity that works" is the optimisation question built from it.
- **Precision / epsilon**: how close an approximate answer must be to the true one to be accepted as good enough. *Where you meet it:* real-valued bisection stops when the remaining range is narrower than this, since there's no exact value to land on.
- **Decision procedure**: an algorithm that answers a single yes-or-no question, such as "is this value feasible," rather than finding the best value directly. *Where you meet it:* the building block parametric search composes with an outer binary search.
