- **Random variable**: a number whose value depends on the outcome of a random process.
- **Expected value**: a probability-weighted average of a random variable's possible values.
- **Independent events**: two events where knowing one happened does not change the probability
  of the other.
- **Uniform random choice**: every outcome in a finite set is equally likely.
- **Harmonic number**: Hₙ = 1 + 1/2 + … + 1/n, the sum of the first n reciprocals.
- **Geometric random variable**: the number of independent trials until the first success.
- **Randomized quicksort, in one line**: pick a pivot uniformly at random, partition the rest
  around it, recurse on both sides.
