- **Stream**: items read once, in order, without going back.
- **Uniform sample**: every k-subset of the items seen so far is equally likely to be the
  sample.
- **Sampling with versus without replacement**: whether an item can be picked more than once.
- **Probability that an item survives a sequence of independent draws**: the product of each
  draw's survival probability.
- **Mathematical induction**: proving a statement for every n by proving it for the base case
  and showing each case implies the next.
- **Min-heap**: a structure that always hands back the smallest item among those it holds.
- **Weight of an item**: a positive number saying how much to favor it in a weighted sample.
